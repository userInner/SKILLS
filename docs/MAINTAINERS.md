# 维护者认领

Agent Skills Index 允许仓库所有者或维护者认领已收录条目，也欢迎提交尚未进入索引的公开 Skill。

## 如何认领

1. 打开[提交或认领 Skill](https://github.com/userInner/SKILLS/issues/new?template=submit-or-claim-skill.yml)表单。
2. 填写公开仓库、`SKILL.md` 路径、许可证、运行环境、依赖与权限。
3. 使用仓库所有者或维护者 GitHub 账号提交。组织仓库可能需要在源仓库补充一次公开确认。
4. 维护者身份和条目信息核验后，条目可标记为“已认领”。

“已认领”只表示维护者身份和公开元数据已经核验，不代表安全认证、质量背书或允许直接安装。直装状态仍需经过许可证、依赖、权限、静态扫描和隔离测试审查。

## README 徽章

认领完成后，可以把下面的 Markdown 放进源仓库 README：

```md
[![Claimed in Agent Skills Index](https://raw.githubusercontent.com/userInner/SKILLS/master/assets/badges/claimed-agent-skill.svg)](https://github.com/userInner/SKILLS)
```

[![Claimed in Agent Skills Index](../assets/badges/claimed-agent-skill.svg)](https://github.com/userInner/SKILLS)

徽章不得用于未认领的仓库，也不得改写为“安全认证”“官方认证”或类似表述。

## Submit or claim a Skill

Repository owners and maintainers can use the same [submission form](https://github.com/userInner/SKILLS/issues/new?template=submit-or-claim-skill.yml). A claimed listing verifies maintainer identity and public metadata only. It is not a security certification or installation endorsement.
